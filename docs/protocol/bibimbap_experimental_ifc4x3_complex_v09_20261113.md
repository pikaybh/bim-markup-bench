## Architecture and immutable model surface

The model-facing authoring surface remains a **complete, ordinary declarative XML state** in the existing frozen toy research namespace `urn:bim-markup-bench:toy:v0` (NOT the normative BIXML language). It contains typed native IFC GlobalId references for known managed elements and stores a literal source IFC SHA-256. It does not contain procedural Create/Move/Resize/Delete operations or direct Python/IfcOpenShell authoring APIs.

`src/runtime/experimental_v9_projection.py::project_ifc_v9` starts from the previous **read-only v0.7 source view** and adds ONLY original `IfcWall` objects whose native `IfcBooleanClippingResult` is exactly one bounded halfspace clipping of an original direct `IfcExtrudedAreaSolid`, and whose **ACTUAL original world mesh** proves a complete 8-corner, 12-triangle axis-aligned bounded box and an original co-linear `IfcPolyline` axis. No shape is flattened/rebuilt. It presents a source-pinned *physical centerline envelope* for these Walls. Original clipping halfspace, original Wall type/material and original `IfcRelConnectsPathElements` connections **remain IFC source-owned opaque entities**; the XML is NOT a complete graph serialization. When there is no newly supported Wall, old v0.7 XML is retained byte-for-byte.

The separate `src/runtime/experimental_v9_complex_compiler.py::compile_declarative_xml_v9` binds original and edited **whole XML states** under the same original source hash, computes typed stable-ID semantic graph changes, and permits only one narrow operation family per candidate. Every candidate is **staged to a new file** with native mesh/root/STEP checks before atomic commit; occupied destinations, multiple operation families and unsupported shapes fail closed. New original source IFC files remain read-only.

## What is and is not supported

1. **Read-only source projection:** v0.9 adds the seven BooleanClipping Walls in the original `topological_test_05` and `topological_test_11` sources to the existing two Slabs / two mapped Columns, respectively. The XML shows honest native original world bounds; **clipping STEP geometry and path connections remain opaque source-owned data**. Any original curved/skewed/voided/space-bounded/multi-halfspace Wall remains opaque. v0.9 does not add arbitrary Wall resize or native clipping regeneration.
2. **Slab square:** exactly one source `IfcExtrudedAreaSolid` with exclusively owned rectangle profile and 2D placement, original world +Y basis from local profile X, actual native 8x12 complete box. Only world `depth` increases to equal unchanged world `width`; original lower anchor stays fixed. No arbitrary slope, other original Slab dimensions, complex holes or local frame rebuilding.
3. **Shared Column height:** exactly two native original `IfcColumn` products with one common source-mapped extrusion and zero unrelated users. Both XML `height` attributes must change together and reach the next source Slab underside within 1cm; no type-sharing break, partial-only one-column edit or mixed pose edit. **The existing one source `IfcExtrudedAreaSolid.Depth` is modified intentionally for both Columns.** Does not support arbitrary shared mapped family edits or multiple independent type sources.
4. **Boolean exterior Door:** exactly one new `Opening` and its new `Door` nodes, with original Boolean Wall host and a safe interior opening offset well away from original path connections, physically true Wall cut and exact native IfcRelVoidsElement/IfcRelFillsElement. New Door contained in source Storey; **original `IfcRelConnectsPathElements` unchanged**, original clipped representation still used. Does not infer/author `IfcSpaceBoundary` or new room objects, nor alter the original host Wall baseline or allow an already-voided wall.
5. **Strict preservation:** immutable original source hash before/after; original schema IFC4X3; all original STEP/Root identity preserved; only exactly 2 original STEP changes for Slab (profile dimension and profile-center point), one shared original mapped extrusion depth STEP change for Columns, or precisely one original Storey membership update for Door. Other original native meshes unchanged. New rooted relation GUIDs deterministic from source hash and type; original native OwnerHistory unchanged; **new only** history timestamp anchored to original source CreationDate for experiment reproducibility (synthetic evidence marker, NOT actual authorship time). All native outputs are byte-stable across a real-clock-second interval on identical input state.
6. **Unsupported:** arbitrary Boolean Walls geometry changes, multi-story hosted Wall edits, arbitrary Slab profile transformation, disconnected shared-type Column updates, v0.9 source IFC2X3/IFC4 (those remain separately handled by v0.8), multiple new Doors, deletion of all unrelated topological Columns, general Space/boundary topology, full building clash oracle, full original 45-case equal-capability direct XML vs Python, any provider inference.
